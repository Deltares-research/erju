# NetCDF Schema (Current)

This document describes the current NetCDF file architecture generated by the database creation pipeline.
Each NetCDF file represents one train passage event and may contain two synchronized modalities:
- Accelerometers (point sensors)
- Fibre optics (distributed sensing, optional per event)

All timeseries are referenced to `event_t0_utc`.

## Notes

- FO blocks (`meta_fo`, `geometry_fo`, `fo`) are only present when FO extraction succeeds for that event.
- `event_t0_utc` is the common time reference for both accelerometer and FO signals.
- Accelerometer and FO are intentionally separated by modality-specific groups.
- `track_number = -1` indicates unknown or missing source value.
